# Task Manager

Приложение для управления задачами в стиле Kanban-доски.

## Функционал

- Регистрация и авторизация
- Три колонки: Новые, В работе, Выполненные
- Добавление и удаление задач
- Перетаскивание задач между колонками (drag & drop)

## Стек

- React + TypeScript
- Redux Toolkit + RTK Query
- React Router v7
- React Hook Form + Zod
- Tailwind CSS
- @dnd-kit
- json-server

## Запуск

1. Установи зависимости:
```bash
npm install
```

2. Запусти json-server (в отдельном терминале):
```bash
npm run server
```

3. Запусти приложение:
```bash
npm run dev
```

4. Открой [http://localhost:5173](http://localhost:5173)
